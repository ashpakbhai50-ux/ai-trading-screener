# 🎯 Hero Zero Stock Options Expiry Scanner\n\nAdded Hero Zero V1 to this repository.\n\n## Filters\n- NSE stock options only, not index options.\n- Nearest available stock-option expiry.\n- Long BUY CE and BUY PE candidates.\n- Premium hard cap ₹1 by default.\n- Configurable high-lot filter (default ≥500).\n- OI, volume and bid/ask spread gates.\n- 15-minute underlying engine: EMA 9/21/50, VWAP, RSI, ATR, ADX, RVOL, 20-bar breakout/breakdown and liquidity sweep/reclaim logic.\n- Mechanical option Entry, SL, T1, T2, T3 and budget calculator.\n\n## Run\n\n    pip install -r requirements.txt\n    streamlit run hero_zero_app.py\n\n## Important\nLot sizes change. `hero_zero_lots.csv` is a starter configuration; replace it with the latest NSE permitted-lot-size data before live use. The scanner is research software and does not guarantee profitable or successful trades. A ₹1 expiry option can lose most or all of its value rapidly. Verify live contract data with your broker/licensed feed before trading.\n
